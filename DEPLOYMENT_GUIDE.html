🐘 Ganpati Store — Complete Deployment Guide

PostgreSQL + Node.js backend deployed free on Render.com

1
Upload Code to GitHub
Free • Takes ~5 minutes • Do this on your Mac
1
Create a GitHub account
Go to github.com → click Sign Up → create a free account with your email.
2
Create a new repository
After logging in → click the green "New" button → name it ganpati-backend → click "Create repository". Leave everything else as default.
3
Install Git on your Mac (if not already)
Open Terminal and run:
git --version
If it shows a version number, Git is installed. If not, it will ask you to install it — click Install.
4
Go to your project folder in Terminal
cd ~/Downloads/ganpati-backend
5
Upload to GitHub — run these commands one by one
# Replace YOUR_GITHUB_USERNAME with your actual GitHub username git init git add . git commit -m "first commit" git branch -M main git remote add origin https://github.com/YOUR_GITHUB_USERNAME/ganpati-backend.git git push -u origin main
⚠️ It will ask for your GitHub username and password. For password, use a Personal Access Token (not your GitHub password). Go to github.com → Settings → Developer Settings → Personal Access Tokens → Generate new token (classic) → check "repo" scope → copy the token and paste it as the password.
2
Create Free PostgreSQL Database on Render
Free • Takes ~3 minutes • Do this in your browser
1
Sign up on Render
Go to render.com → click Get Started for Free → sign up with your GitHub account (easiest).
2
Create a PostgreSQL database
In Render dashboard → click New + → select PostgreSQL → fill in:
Name: ganpati-db
Database: ganpati_store
User: ganpati_user
Region: Singapore (closest to India)
Plan: Free
Click Create Database. Wait ~2 minutes for it to be ready.
3
Copy the connection string
Once the database is created, scroll down to "Connections" section → find "External Database URL" → click the copy button. Save this — you need it in the next phase.
It looks like: postgresql://ganpati_user:somepassword@dpg-xxxx.singapore-postgres.render.com/ganpati_store
4
Run the database setup SQL
In Render dashboard → click your database → find "PSQL Command" → click the copy button → paste it in your Terminal. This opens the database shell. Then copy and paste the entire contents of setup.sql file and press Enter. Type \q to exit.
This creates all the tables (users, products, orders, cart, wishlist) and fills in all 44 products automatically.
3
Deploy Backend on Render
Free • Takes ~5 minutes
1
Create a Web Service on Render
In Render dashboard → click New + → select Web Service → connect your GitHub account → select the ganpati-backend repository.
2
Configure the service
Name: ganpati-backend
Region: Singapore
Branch: main
Build Command: npm install
Start Command: node server.js
Plan: Free
3
Add Environment Variables
Scroll down to "Environment Variables" section → add these one by one:
DATABASE_URL = (paste the External Database URL you copied in Phase 2)

JWT_SECRET = ganpati_navin_store_secret_9876543210abcdef

PORT = 5000
4
Click "Create Web Service"
Render will now build and deploy your backend. Watch the logs at the bottom. When you see "Server running on port 5000" — it's live! 🎉
Your backend URL will be something like: https://ganpati-backend.onrender.com
Copy this URL — you need it for the next phase.
5
Test your backend
Open your browser and go to:
https://ganpati-backend.onrender.com/
You should see: {"message":"🐘 Ganpati Store API is running!"}
4
Connect Your Frontend HTML to the Backend
Edit your HTML file • Takes ~2 minutes
1
Open your HTML file in a text editor
Open ganpati-store-namsai.html in any text editor (TextEdit on Mac, or VS Code).
2
Add api.js before your existing script
Find the line </head> in your HTML and add this line just before it:
<script src="api.js"></script>
Put the api.js file in the same folder as your HTML file.
3
Update the API URL in api.js
Open api.js → find the first line and replace with your Render URL:
const API_BASE = 'https://ganpati-backend.onrender.com/api';
4
Replace the 4 key functions in your HTML
